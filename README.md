# Språkkafé Oslo

Directorio comunitario, móvil primero, para encontrar actividades gratuitas donde practicar noruego, conocer personas y conectar con la vida local en Oslo.

Producción: https://sprakkafe-oslo.vercel.app

## Estado

El MVP está activo y estable. Incluye búsqueda y filtros, actividades de hoy, páginas de actividad y organización, suscripción mediante MailerLite, SEO técnico, accesibilidad y cabeceras de seguridad.

La información se publica desde fuentes oficiales y cualquier cambio requiere revisión administrativa antes de modificar los datos.

## Desarrollo

Requiere Node.js 22.

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run build
```
